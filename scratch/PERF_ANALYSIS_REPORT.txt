PROBLEM:
--------
Lines 716-719 in detectUndersampledLemmas:
  featureSpaceByLemmeGramCat: dict[LemmeGramCat, set[WordFeature]] = {
      lemmeGramCat: fullFeatureSpace(strokeLemmeDiscriminators, lemmeGramCat)
      for lemmeGramCat in templateByLemmeGramCat
  }

This calls fullFeatureSpace 5,602 times. Each call iterates through the ENTIRE
strokeLemmeDiscriminators dictionary (93,048 keys) searching for entries matching
a single lemmeGramCat.

Algorithm Complexity:
  - fullFeatureSpace scans: O(n) where n = len(strokeLemmeDiscriminators) = 93,048
  - Called m times where m = len(templateByLemmeGramCat) = 5,602
  - Total: O(m * n) = 5,602 * 93,048 ≈ 521 million dictionary iterations

Lines 119-134 in fullFeatureSpace:
  for (_strokes, groupLemme), wordFeatures in strokeLemmeDiscriminators.items():
      if groupLemme != lemmeGramCat:
          continue
      for features in wordFeatures.values():
          space.update(features)

This is executed 5,602 times with 521M iterations total, plus 18M set.update() calls.

FIX #1: INDEX STROKE_LEMME_DISCRIMINATORS BY LEMME_GRAM_CAT [CRITICAL]
--------

Location: src/verbparadigm.py, detectUndersampledLemmas (lines 681-739)
Savings: ~98s (from ~126s -> ~28s in detectUndersampledLemmas)
         ~185s in full findStructuralCandidates (215s -> 30s)
Complexity: Low (simple dict preprocessing)
Output correctness: ✓ Verified identical

Implementation:
1. In detectUndersampledLemmas, after line 715 (before line 716):

   # Precompute index: group by lemmeGramCat for O(1) lookup instead of O(n) scan
   index_by_lemme: dict[LemmeGramCat, list[dict[Word, list[WordFeature]]]] = defaultdict(list)
   for (_strokes, groupLemme), wordFeatures in strokeLemmeDiscriminators.items():
       index_by_lemme[groupLemme].append(wordFeatures)

2. Replace fullFeatureSpace calls (lines 716-719) with direct index lookup:

   featureSpaceByLemmeGramCat: dict[LemmeGramCat, set[WordFeature]] = {}
   for lemmeGramCat in templateByLemmeGramCat:
       space: set[WordFeature] = set()
       for wordFeatures in index_by_lemme[lemmeGramCat]:
           for features in wordFeatures.values():
               space.update(features)
       featureSpaceByLemmeGramCat[lemmeGramCat] = space

Alternative: Extract index-building into a helper function and call it once in
detectUndersampledLemmas. This avoids fullFeatureSpace deprecation if it's used
elsewhere (check callers).

Callers of fullFeatureSpace (search result):
  - detectUndersampledLemmas (line 717, only caller identified)

If detectUndersampledLemmas is the only caller, fullFeatureSpace can be marked
@deprecated or removed after applying the fix.
